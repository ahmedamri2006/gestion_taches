## Utilisation
- Choisir 1 pour ajouter une tâche.
- Choisir 2 pour afficher les tâches.
- Choisir 3 pour rechercher une tâche.
- Choisir 0 pour quitter le programme.
## Description
Application Python en console permettant de gérer une liste de tâches.

## Fonctionnalités
- Ajouter une tâche avec un titre non vide.
- Afficher toutes les tâches enregistrées.
- Rechercher une tâche par mot-clé.
- Quitter l'application.

## Technologies utilisées
- Python
- Git
- GitHub

## Exécution
1. Ouvrir le dossier du projet dans Visual Studio Code.
2. Ouvrir le fichier `main.py`.
3. Cliquer sur **Run Python File** pour lancer le programme.
